Vous trouverez dans ce dépôt deux documents : un fichier PDF et un fichier Python.

Le PDF présente les fondements mathématiques de plusieurs modèles génératifs, notamment les **Score-Based Generative Models (SGM)**, le **Probability Flow**, le **Flow Matching (FM)**, l’**Optimal Flow Matching (OFM)** et le **Rectified Flow Matching (RFM)**.

Le code permet d’implémenter ces différentes méthodes et de reproduire les expériences numériques et les comparaisons présentées dans le mémoire, notamment sur des distributions en dimension 2.
